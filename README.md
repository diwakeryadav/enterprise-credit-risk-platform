# # Enterprise Credit Risk Prediction Platform

## Project Overview

This is an End-to-End Machine Learning system that predicts the probability of loan default before credit approval. The objective is to assist the risk management and collection department in making data-driven lending decisions by combining statistical analysis, machine learning, explainable AI and MLOPS practices. 

This project aims to replicate and simulate the complete lifecycle of a production banking application, this project includes.

1. Data Validation
2. Feature Engineering
3. Model Training 
4. Model Explainability
5. API Deployment
6. Experiment Tracking 
7. Monitoring
8. Model Retraining Pipeline
9. Automated Retraining 

## Business Problem

Financial institutions lose crore of rupees every year to loan defaulters. Traditional rule-based credit assessment systems often fail to capture complex relationships between customer financial history, employment information, repayment behaviour, and credit risk.

The objective of this project is to estimate the probability that a customer will default on a loan before approval. The predicted probability can then be incorporated into the bank's risk assessment workflow to improve lending decisions, reduce expected losses, and support explainable decision-making.

## Business Value

This system is designed to support multiple business stakeholders.

- Risk teams receive an estimated probability of default for each applicant.

- Business teams can improve portfolio quality while maintaining customer growth.

- Compliance teams can understand model decisions through explainability techniques.

- Engineering teams receive a deployable prediction service suitable for production environments.

- Management gains measurable business metrics such as reduced default rates and improved lending efficiency.

The project emphasizes reproducibility, scalability, and transparency, reflecting practices commonly used in enterprise banking environments.
